# Индекс по сценариям использования

«У меня вот такая ситуация — что мне нужно?»

## Прохожу аудит / готовлюсь к сертификации

- **ISO/IEC 27001** → пакет `iso-27001-aligned` *(планируется)*
- **СТО БР ИББС / ГОСТ 57580** → пакет `bank-of-russia-aligned` *(планируется)*
- **PCI DSS 4.0** → пакет `pci-dss-aligned` *(планируется)*
- **SOC 2** → пакет `soc-2-aligned` *(планируется)*

## Обрабатываю персональные данные граждан РФ

→ пакет `152-fz-aligned` *(планируется)*. Включает обязательные документы по ФЗ-152 и Приказам ФСТЭК.

## Я — субъект критической информационной инфраструктуры (КИИ)

→ пакет `kii-subject` *(планируется)*. Документы по 187-ФЗ, взаимодействие с НКЦКИ.

## Разрабатываю программное обеспечение

→ пакет `software-development` *(планируется)*. SDLC, Secure SDLC, DevSecOps, supply chain.

## У меня IT-компания, хочу аккредитацию

→ пакет `accredited-it-company` *(планируется)*. Документы для попадания в реестр аккредитованных IT-компаний Минцифры.

## Работаю преимущественно в облаке

→ пакет `cloud-first` *(планируется)*. Cloud governance, CSPM, FinOps, SaaS управление.

## У меня производство, есть АСУ ТП

→ пакет `industrial` *(планируется)*. OT/ICS security, координация safety/security.

## Случилось…

### Утечка данных
→ POL-SEC-001 (реагирование), POL-DAT-001 (защита данных), POL-DAT-005 (DSR), POL-SEC-002 (уведомление о нарушениях)

### Уволился ключевой человек, остался без знаний
→ POL-HRM-014 (bus factor), POL-OPS-017 (runbooks), POL-HRM-013 (управление критическими знаниями)

### Подрядчик с доступом, переживаю за риски
→ POL-SUP-001 (аутсорсинг), POL-SUP-005 (доступ подрядчиков), POL-SUP-012 (контроль действий)

### Внедряем 1С / большую ERP
→ POL-SAA-005 (SoD), POL-SAA-007 (кастомизация ERP), POL-OPS-001 (управление изменениями)

### Активно используем ChatGPT / Claude / Copilot
→ POL-AIG-001 (использование AI), POL-DEV-008 (AI-помощники в разработке), POL-AIG-003 (защита от утечек)

### Постоянно проникает фишинг
→ POL-NET-013 (email security: DMARC/SPF/DKIM), POL-HRM-005 (security awareness), POL-SEC-018 (out-of-band верификация)
