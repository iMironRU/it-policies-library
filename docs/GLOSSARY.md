# Глоссарий терминов

## Базовые понятия

**Политика** — документ верхнего уровня, описывающий принципы и подходы. В этой библиотеке используется как зонтичный термин для всех документов.

**Стандарт** — документ, устанавливающий конкретные требования (что должно соблюдаться).

**Регламент** — документ, описывающий последовательность действий в процессе.

**Инструкция** — документ для конкретной роли с пошаговыми действиями.

## Аббревиатуры

- **AUP** — Acceptable Use Policy, политика допустимого использования
- **BCP** — Business Continuity Planning, непрерывность бизнеса
- **CISO** — Chief Information Security Officer, руководитель ИБ
- **CMDB** — Configuration Management Database
- **DLP** — Data Loss Prevention, предотвращение утечек
- **DRP** — Disaster Recovery Plan, план аварийного восстановления
- **DSR** — Data Subject Request, запрос субъекта данных
- **EDR** — Endpoint Detection and Response
- **JIT** — Just-in-Time access, доступ по требованию
- **JML** — Joiner/Mover/Leaver, жизненный цикл сотрудника
- **MFA** — Multi-Factor Authentication
- **NHI** — Non-Human Identities, нечеловеческие идентичности (сервисные учётки)
- **OLA** — Operational Level Agreement
- **OT/ICS** — Operational Technology / Industrial Control Systems
- **PAM** — Privileged Access Management
- **PSIRT** — Product Security Incident Response Team
- **RTO/RPO** — Recovery Time/Point Objective
- **SBOM** — Software Bill of Materials
- **SDLC** — Software Development Life Cycle
- **SIEM** — Security Information and Event Management
- **SLA** — Service Level Agreement
- **SOC** — Security Operations Center
- **SoD** — Segregation of Duties, разделение обязанностей
- **SRE** — Site Reliability Engineering
- **TPRM** — Third-Party Risk Management
- **UC** — Underpinning Contract
- **VDP** — Vulnerability Disclosure Programme
- **WORM** — Write Once, Read Many (неизменяемое хранение)

## Российская специфика

- **АСУ ТП** — автоматизированные системы управления технологическими процессами
- **ГИС** — государственные информационные системы
- **ГосСОПКА** — государственная система обнаружения, предупреждения и ликвидации последствий компьютерных атак
- **ИСПДн** — информационные системы персональных данных
- **КИИ** — критическая информационная инфраструктура
- **НКЦКИ** — Национальный координационный центр по компьютерным инцидентам
- **ПДн** — персональные данные
- **СЗИ** — средства защиты информации
- **СКЗИ** — средства криптографической защиты информации
- **УКЭП** — усиленная квалифицированная электронная подпись
- **ФСТЭК** — Федеральная служба по техническому и экспортному контролю
- **ЭП** — электронная подпись
