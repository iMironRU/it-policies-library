# История изменений — POL-SEC-001 Политика реагирования на инциденты ИБ

## [1.0.0] — 2026-05-19

### Added
- Первоначальная версия шаблона
- Четырёхуровневая классификация инцидентов (P1–P4) с временными нормативами реагирования
- Восемь типов инцидентов для категоризации в реестре
- Шестифазный процесс реагирования (Подготовка, Обнаружение, Сдерживание, Расследование, Восстановление, Постинцидентный анализ)
- Таблица обязательных уведомлений регуляторов (РКН 72 ч., НКЦКИ 3/24 ч.) с актуальными основаниями
- Раздел коммуникаций с разделением внутренних, внешних и регуляторных
- Требования к документированию карточек инцидентов
- Метрики: MTTD, MTTR, % постинцидентного анализа, % выполнения рекомендаций
- Маппинг на ISO/IEC 27035-1:2023, NIST SP 800-61 Rev.2, CIS Controls v8 Control 17, ФЗ-152 (ст. 21 ч. 3.1), 187-ФЗ, ФСТЭК Приказ 17/21/239
- Руководство с российской спецификой по уведомлению РКН и НКЦКИ, разбором 7 частых ошибок и ответами на типовые ситуации
