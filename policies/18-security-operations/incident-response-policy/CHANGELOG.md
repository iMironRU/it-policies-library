# История изменений — POL-SEC-001 Политика реагирования на инциденты ИБ

## [1.0.0] — 2026-10-02

### Added
- Первоначальная версия шаблона
- 4-уровневая классификация инцидентов (P1–P4) по критичности с примерами
- Классификация по типу (несанкционированный доступ, malware, утечка, DoS, фишинг, нарушение политики, физическая угроза)
- Пошаговый порядок реагирования: обнаружение → регистрация → сдерживание → расследование → эскалация → устранение → постинцидентный разбор
- Сроки уведомления РКН при утечке ПДн: 24 ч (первичное) / 72 ч (расширенное) согласно ч. 3.1 ст. 21 ФЗ-152
- Сроки уведомления НКЦКИ при инцидентах КИИ: 24 ч согласно ФЗ-187 и Приказу ФСБ № 367
- Таблица SLA по реагированию: P1 — первичный отклик 30 мин, устранение 24 ч
- Состав и ролевая матрица группы реагирования (Incident Commander, ИБ, IT, юристы, PR)
- Требования к хранению материалов инцидента и цепочке доказательств
- Требование ежегодных tabletop exercises
- Маппинг на ISO/IEC 27001:2022 A.5.24–A.5.28, ISO/IEC 27035-1:2023, NIST SP 800-61r3, ФЗ-152, ФЗ-187, ГОСТ Р 59547-2021
- Полное руководство по применению (GUIDE.md): структура команды для малых команд, настройка канала сообщений, сценарии тренировок, типичные ошибки
