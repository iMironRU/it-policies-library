# POL-SEC-001 — Политика реагирования на инциденты информационной безопасности

**Статус:** Draft · **Зрелость:** ★ Core · **Версия:** 1.0

## Зачем нужна эта политика

Без чёткого плана реагирования инцидент ИБ превращается в хаос: команды не знают, кто принимает решения, данные затираются в попытке «починить», регуляторные сроки пропускаются. Политика фиксирует минимальный набор: как сообщить об инциденте, кто что делает, в какие сроки нужно уведомить РКН и НКЦКИ, и как провести разбор, чтобы не повторить ту же ошибку.

## Контекст применения

Подходит для любых организаций — от малого бизнеса до крупных компаний. Для малых команд (до 20 человек) роли группы реагирования совмещаются; для крупных — детализируются в отдельных регламентах (runbooks) поверх этой политики.

**Обязательна** для организаций, обрабатывающих персональные данные (ФЗ-152): уведомление РКН в 24/72 часа — законодательное требование, не внутреннее правило.

**Обязательна** для субъектов КИИ (ФЗ-187): требует уведомление НКЦКИ в 24 часа.
