# POL-RUS-001 — Политика обеспечения безопасности объектов КИИ

**Maturity:** ◆ Standard  
**Владелец:** CISO  
**Статус:** draft  
**ⓘ Conditional:** только для субъектов КИИ

---

## Зачем нужна эта политика

ФЗ-187 создал отдельный регуляторный контур для организаций, чья деятельность критически важна для функционирования государства и экономики. Без специальной политики субъект КИИ сталкивается с четырьмя проблемами одновременно:

- **Не выполнено категорирование** — без актов категорирования, направленных в ФСТЭК, организация технически нарушает ФЗ-187 уже с момента получения статуса субъекта КИИ.
- **Нет взаимодействия с НКЦКИ** — при инциденте не выполняется обязательное уведомление; ФСБ может запросить объяснения.
- **Меры защиты не соответствуют Приказу ФСТЭК № 239** — в ходе проверки ФСТЭК выявляются несоответствия, выдаётся предписание.
- **Уголовная ответственность** — ст. 274.1 УК РФ действует с 2017 года; неправомерное воздействие на объект КИИ, совершённое в том числе по халатности должностных лиц, может повлечь реальный срок.

Эта политика отвечает на вопросы:
- Как определить, является ли организация субъектом КИИ?
- Как провести категорирование и что направить в ФСТЭК?
- Какие меры защиты обязательны для каждой категории?
- Как взаимодействовать с НКЦКИ и в какие сроки уведомлять?
- Кто отвечает за безопасность КИИ внутри организации?

## Ключевые решения при внедрении

1. **Нужно ли вообще**: определить статус субъекта КИИ — первый шаг. Перечень типовых объектов КИИ для отраслей публикуется на сайте ФСТЭК. Консультация с юристом, специализирующимся на ФЗ-187, желательна ещё до начала категорирования.

2. **Состав комиссии по категорированию**: Постановление № 127 требует привлечь представителей всех подразделений, которые эксплуатируют или обеспечивают функционирование потенциальных объектов КИИ. Для промышленных предприятий — обязательно представители АСУ ТП.

3. **«Нет значимых объектов»**: многие организации проводят категорирование и получают результат «ни один объект не является значимым». Это законный исход — его нужно оформить актом и тоже направить в ФСТЭК.

4. **Сертифицированные СЗИ**: для значимых объектов КИИ требуются сертифицированные ФСТЭК средства защиты. Реестр сертифицированных СЗИ публикуется на fstec.ru. Переход с несертифицированных решений — трудоёмкий проект; планируйте его заблаговременно.

5. **ГосСОПКА**: для значимых объектов КИИ 1 категории подключение к ГосСОПКА де-факто обязательно. Для 2 и 3 категории — взаимодействие через НКЦКИ при инцидентах; собственный SOC необязателен, но рекомендован для 2 категории.

## Регуляторный контекст и санкции

| Норма | Последствие нарушения |
|---|---|
| ФЗ-187 ст. 7 — несоблюдение порядка категорирования | Предписание ФСТЭК; повторное нарушение — административная ответственность |
| ФЗ-187 ст. 9 — ненадлежащее взаимодействие с НКЦКИ | Проверка ФСБ; возможное предписание |
| Приказ ФСТЭК №239 — несоответствие мер защиты | Предписание ФСТЭК об устранении; приостановка работы ИС до устранения |
| УК РФ ст. 274.1 ч. 3 — нарушение правил эксплуатации объекта КИИ, повлёкшее ущерб | До 6 лет лишения свободы для должностного лица |
| УК РФ ст. 274.1 ч. 1 — создание/распространение вредоносного ПО для КИИ | До 10 лет лишения свободы |

## Хронология обязательств субъекта КИИ

```
Статус субъекта КИИ установлен
│
├─► 180 дней → Завершить категорирование; направить акты в ФСТЭК
│
├─► При значимых объектах: разработать систему безопасности
│   (сроки согласно предписаниям ФСТЭК и договорённостям)
│
├─► Непрерывно: мониторинг событий безопасности
│
├─► При инциденте: незамедлительно уведомить НКЦКИ
│   (1 кат. — 3 часа; 2/3 кат. — 24 часа; детали — 48 часов)
│
└─► Не реже 1 раза в 5 лет: пересмотр категорий значимости
```
