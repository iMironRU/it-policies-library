# История изменений — POL-RUS-001 Политика обеспечения безопасности объектов КИИ

## [1.0.1] — 2026-10-03

### Исправления (по результатам кросс-политического ревью)
- §7.2: срок уведомления НКЦКИ обновлён в соответствии с Приказом ФСБ от 19.06.2023 № 338 (вместо Приказа ФСБ № 367 от 24.07.2018): добавлена дифференциация — **3 часа** при атаке с подтверждёнными последствиями, **24 часа** без подтверждённых последствий; 3-часовой срок был «рекомендацией», теперь — нормативное требование

## [1.0.0] — 2026-10-03

### Added
- Первоначальная версия шаблона
- Определение статуса субъекта КИИ: 12 отраслей ФЗ-187, порядок определения применимости
- Категорирование: порядок по ПП РФ №127, состав комиссии, 5 критериев значимости, 3 категории + незначимые объекты, сроки направления сведений в ФСТЭК (10 дней)
- Меры защиты по Приказу ФСТЭК №239: 13 обязательных классов мер (ИАФ, УПД, ОПС, ЗНИ, АУД, АВЗ, СОВ, ОЦЛ, ОДТ, ЗТС, ЗИС, ИНЦ, УКФ); требования к классам СЗИ/СКЗИ по категориям
- Требования к СЗИ: сертификация ФСТЭК/ФСБ, требования к классам по категориям (1 кат. → СЗИ кл. 4, КС3; 2 кат. → кл. 5, КС2; 3 кат. → кл. 6, КС1)
- Сегментация: изоляция от корпоративной сети, требования к АСУ ТП, ограничение Internet-выхода
- Взаимодействие с НКЦКИ/ГосСОПКА: подключение, сроки уведомления (1 кат. — 3ч; 2/3 кат. — 24ч; детали — 48ч; основание — ФЗ-187 ст. 9 + Приказ ФСБ №367), перечень данных
- Разработка системы безопасности: последовательность (исходные данные → модель угроз → требования → проект → внедрение → испытания → ввод)
- Управление уязвимостями: ежеквартальное сканирование, 30 дней на критические, обязательное тестирование патчей
- Управление персоналом: допуск, подрядчики, обязательный инструктаж
- Непрерывность: RTO/RPO для объектов КИИ, тестирование восстановления дважды в год, ежегодные учения
- Государственный контроль: ФСТЭК ст. 13 ФЗ-187, обязательства по предписаниям
- Уголовная ответственность по ст. 274.1 УК РФ (до 10 лет)
- GUIDE.md: алгоритм определения субъекта КИИ, типовые объекты по отраслям, последовательность категорирования, форма акта, направление в ФСТЭК, порядок подключения к ГосСОПКА, шаблон первичного уведомления НКЦКИ, чеклист документов для проверки ФСТЭК, таблица классов СЗИ по категориям

### Исправления (по результатам AI-ревью)
- §7.2: убрана несуществующая дифференциация "3 часа / 24 часа" по категориям в Приказе ФСБ №367 — правильно: 24 часа единый срок для всех категорий; 3 часа оставлены как рекомендуемый внутренний SLA
- §7.2: "48 часов детальный отчёт" явно обозначено как внутреннее требование, не установленное Приказом №367
- §6.3: убраны "классы 4/5/6 СЗИ" — эта терминология относится к Приказам №17/21, а не к №239; заменено на состав мер по Приложениям 1–3 к Приказу №239; добавлены классы СКЗИ (КА/КВ/КС) по категориям
- §6.3: добавлено требование о проверке СЗИ/СКЗИ в актуальных реестрах ФСТЭК/ФСБ
- §7.1: добавлен Приказ ФСБ №368 (Порядок взаимодействия с ГосСОПКА); исправлены наименования Приказов №366/367
- §8.1: добавлен Приказ ФСТЭК №235 (создание системы безопасности КИИ) рядом с №239
- §11.2: "ст. 13 ФЗ-187" → "ст. 12 ФЗ-187" для государственного контроля (ст. 13 — об ответственности)
- §13: исправлены санкции по ст. 274.1 УК РФ (ч.1 — до 6 лет; ч.2 — до 5 лет; ч.3-5 — до 10 лет); добавлена специальная норма ст. 13.12.1 КоАП РФ для субъектов КИИ
