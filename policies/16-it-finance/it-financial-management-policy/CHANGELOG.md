# История изменений — POL-FIN-001 Политика управления IT-финансами

## [1.0.0] — 2026-10-03

### Added
- Первоначальная версия шаблона
- Классификация IT-затрат: CAPEX vs OPEX с порогом `{{ПОРОГ_КАПЕКС}}`; 8 статей IT-бюджета включая резерв `{{РЕЗЕРВ_БЮДЖЕТА}}`
- Бюджетирование: ежегодный цикл с дедлайном `{{СРОК_ПОДАЧИ_БЮДЖЕТА}}`; обязательный состав заявки (TCO, план оптимизации, перенесённые обязательства); согласование отклонений свыше 10% или `{{ПОРОГ_СОГЛАСОВАНИЯ_ФД}}`; ежеквартальный прогноз
- Закупки IT: конкурентный отбор выше `{{ПОРОГ_ТЕНДЕРА}}` (≥3 предложения); три задокументированных основания для исключений; TCO-оценка для крупных проектов; обязательные договорные условия (фиксация цены, право аудита, exit strategy, ПДн)
- Лицензионный реестр: состав (тип, кол-во, срок, стоимость); ежеквартальная сверка план/факт; правило осознанного продления за 60 дней до истечения
- Распределение IT-затрат: три модели (централизованная / show-back / charge-back); таблица баз распределения по типам затрат
- Отчётность: три горизонта (ежемесячно → ФД, ежеквартально → ФД + Утверждающий, ежегодно → Утверждающий) с содержанием каждого отчёта
- Ежегодный план оптимизации: неиспользуемые лицензии, legacy с высоким TCO, консолидация, облачные аномалии
- Нормативная база: ФСБУ 6/2020, ФСБУ 14/2022, НК РФ гл. 25, ФЗ-402 — российская специфика учёта IT-активов
- GUIDE.md: ориентиры по порогам (CAPEX, тендер), сравнительная таблица моделей распределения, методика создания лицензионного реестра, TCO-таблица on-premise vs cloud, FinOps-практики для облака

### Исправления (по результатам AI-ревью)
- §4.1: исправлена критическая ошибка в классификации ПО — «perpetual license = CAPEX» заменено на корректную схему по ФСБУ 14/2022: исключительные права → НМА (CAPEX); неисключительные лицензии (включая perpetual) → РБП (OPEX); добавлен критерий СПИ >12 мес. и ФСБУ 26/2020 для капвложений
- §5: добавлен подраздел §5.2 «Утверждение бюджета» (этап между подачей заявки и исполнением); нумерация §5.2–5.4 → §5.3–5.5
