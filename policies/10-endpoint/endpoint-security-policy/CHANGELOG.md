# История изменений — POL-END-001 Политика безопасности конечных точек

## [1.0.0] — 2026-10-02

### Added
- Первоначальная версия шаблона
- Требования к реестру устройств и первоначальной настройке (baseline)
- Обязательная регистрация в MDM со сроком {{СРОК_РЕГИСТРАЦИИ_УСТРОЙСТВА}}
- Требования к аутентификации: блокировка экрана, PIN, биометрия
- Требования к полному шифрованию диска (FDE): BitLocker/FileVault/встроенное шифрование
- Управление программным обеспечением: реестр одобренного ПО, запреты, отключение прав локального администратора
- Требования к съёмным носителям: шифрование, запрет автозапуска
- Таблица агентов безопасности: EPP/EDR/межсетевой экран/DNS-фильтрация
- SLA патчинга по CVSS v3.1: критичные/высокие/средние с параметризованными сроками
- Централизованное развёртывание обновлений через MDM/WSUS; автоматическая блокировка устройств без обновлений
- Периодическое сканирование уязвимостей {{ПЕРИОДИЧНОСТЬ_СКАНИРОВАНИЯ}}
- Процедура при утере/краже: уведомление ≤ 2 часов, удалённое стирание, оценка ПДн
- Процедура вывода из эксплуатации: криптографическое стирание, снятие с учёта в MDM
- Требования к BYOD: минимальный набор, стирание только корпоративного контейнера
- Ежемесячный отчёт о соответствии: покрытие MDM, процент актуальных обновлений, незакрытые CVE >7.0
- Маппинг на ISO/IEC 27001:2022 A.8.1, A.8.7-8.9, CIS Controls v8, ФСТЭК Приказ 21 АВЗ.1
- Руководство по применению (GUIDE.md): выбор сроков патчинга, baseline, MDM, типичные ошибки, особенности ПДн
