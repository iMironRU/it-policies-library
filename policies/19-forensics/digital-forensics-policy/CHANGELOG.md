# История изменений — POL-FOR-001 Политика цифровой криминалистики и судебного удержания доказательств

## [1.0.1] — 2026-10-04

### Исправления (по результатам кросс-политического ревью)
- §7.4 (новый): добавлена сводная таблица минимальных сроков хранения журналов по всей библиотеке (8 строк, охватывает POL-END-001, POL-NET-001, POL-SEC-001, POL-CMP-001, POL-RUS-001, POL-FIN-001); правило приоритета при конфликте сроков — применяется наибольший

## [1.0.0] — 2026-10-02

### Added
- Первоначальная версия шаблона
- Перечень оснований для инициации криминалистического расследования: инциденты ИБ, внутренние нарушения, судебные запросы, проверки регуляторов
- Процедура судебного удержания (Legal Hold): введение за {{СРОК_УВЕДОМЛЕНИЯ_О_HOLD}}, технические меры (приостановка автоудаления, резервные копии, ограничение доступа), порядок отмены
- Принципы сбора доказательств: неизменности, документирования, верификации хэшами (SHA-256), минимального вмешательства
- Порядок сбора от летучего к постоянному: RAM dump → сетевые соединения → процессы → временные файлы → swap → образ диска → системные журналы → внешние журналы
- Особенности сбора в облачных средах: официальные API, заверенный экспорт с хэшами и метаданными
- Криминалистический образ: {{ИНСТРУМЕНТ_КРИМИНАЛИСТИКИ}}, write blocker, SHA-256/MD5 верификация
- Хранение и защита доказательств: цепочка хранения (12 обязательных атрибутов), {{ХРАНИЛИЩЕ_ДОКАЗАТЕЛЬСТВ}} с изоляцией и WORM
- Сроки хранения: по инцидентам ({{СРОК_ХРАНЕНИЯ_ДОКАЗАТЕЛЬСТВ_ИНЦИДЕНТ}}), по судебным делам ({{СРОК_ХРАНЕНИЯ_ДОКАЗАТЕЛЬСТВ_СУДЫ}}), базовые логи ({{СРОК_ХРАНЕНИЯ_ЛОГОВ}})
- Требования к анализу: работа на копии, изолированная среда, документирование инструментов и методологии
- Привлечение внешних экспертов: NDA, передача копий с хэшами, письменный отчёт
- Взаимодействие с правоохранительными органами: проверка оснований, передача через юриста, копия vs оригинал
- Требования к допустимости электронных доказательств в РФ: ГПК/АПК/УПК, нотариальный осмотр для нестатичных данных, метаданные
- Конфиденциальность расследования: need-to-know, NDA участников, ФЗ-152
- Матрица ответственности: ИБ / Следователь / Юрист / IT / HR / Руководство
- Метрики: время до начала сбора, покрытие журналированием, полнота цепочки хранения, соблюдение срока Legal Hold
- Руководство по применению (GUIDE.md): 30-минутный протокол первого реагирования, создание образа (dd/dcfldd/FTK Imager), сбор летучих данных PowerShell, шаблон уведомления о Legal Hold, шаблон журнала цепочки хранения, нотариальный осмотр, open source инструменты анализа
