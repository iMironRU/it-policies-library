# GUIDE — POL-FOR-001 Политика цифровой криминалистики и судебного удержания доказательств

Руководство по применению: как правильно собрать цифровые доказательства, оформить Legal Hold и не сделать ошибок, которые разрушат дело.

---

## Первые действия при инциденте: золотые 30 минут

При обнаружении инцидента с потенциальными юридическими последствиями:

```
1. НЕ перезагружать и НЕ выключать систему (если в памяти — активный процесс атаки).
2. НЕ запускать антивирус в режиме лечения (уничтожит артефакты).
3. НЕ пытаться «исправить» — сначала задокументировать.
4. Сделать снимок экрана или фото монитора (дата/время видны).
5. Вызвать {{РОЛЬ_СЛЕДОВАТЕЛЬ}} / {{ОТВЕТСТВЕННЫЙ_ЗА_ИБ}}.
6. Изолировать систему от сети (отключить кабель или перевести в VLAN карантина) — НЕ выключать.
7. Начать сбор летучих данных (RAM, сетевые соединения, процессы).
```

## Создание криминалистического образа диска

### Инструменты (open source)

**dd / dcfldd:**
```bash
# Создание образа диска
dcfldd if=/dev/sda of=/forensics/evidence/server01-sda.img \
  hash=sha256 hashwindow=512M hashlog=/forensics/evidence/server01-sda.sha256 \
  bs=512 conv=noerror,sync

# Верификация образа
sha256sum /forensics/evidence/server01-sda.img > /forensics/evidence/server01-sda.sha256.verify
diff /forensics/evidence/server01-sda.sha256 /forensics/evidence/server01-sda.sha256.verify
```

**FTK Imager (GUI, бесплатен):**
1. File → Create Disk Image → Physical Drive
2. Выбрать носитель
3. Add Image Destination → E01 формат (встроенные хэши)
4. По завершении: Verify Images — проверить совпадение MD5/SHA-1

## Сбор летучих данных (Windows)

```powershell
# Список запущенных процессов с деталями
Get-Process | Select-Object Name, Id, StartTime, MainWindowTitle |
  Export-Csv C:\forensics\processes.csv

# Сетевые соединения
netstat -ano > C:\forensics\netstat.txt

# Автозагрузка
Get-CimInstance Win32_StartupCommand | Export-Csv C:\forensics\startup.csv

# Журнал событий (Security, System, Application — последние 7 дней)
$start = (Get-Date).AddDays(-7)
Get-WinEvent -LogName Security -After $start |
  Export-Csv C:\forensics\security-events.csv

# Список активных сессий
query session > C:\forensics\sessions.txt
qwinsta /server:localhost >> C:\forensics\sessions.txt
```

## Нотариальный осмотр сайта и переписки

Для фиксации нестатичных данных (веб-страницы, переписка в мессенджерах):

**Что фиксирует нотариус:**
- URL, дата и время осмотра
- содержимое страницы в момент осмотра
- скриншоты с подтверждением даты (например, через синхронизацию с атомарными часами)

**Когда использовать:**
- веб-сайт конкурента нарушает ваши права (публикации, контент)
- переписка в мессенджерах как доказательство нарушения договора
- нарушение деловой репутации в интернете
- зафиксировать публичную информацию до её удаления

**Практика**: нотариальный осмотр стоит инициировать в первые 24–48 часов после обнаружения потенциально значимого контента — он может быть удалён в любой момент.
