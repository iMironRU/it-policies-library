# История изменений — POL-IAM-001 Политика управления паролями

## [1.0.1] — 2026-05-22

### Fixed
- Срок уведомления при компрометации привилегированной учётной записи: 30 минут → 1 час (предыдущий срок нереалистичен для организаций без круглосуточного дежурства)
- Формулировка хранения хэшей паролей: убрана двусмысленная конструкция «не «соль» отсутствует»
- Добавлена рекомендация TLS 1.3 в раздел технических мер (был только TLS 1.2)
- Добавлена ссылка на ФЗ-152 ст. 19 в раздел внешних стандартов

## [1.0.0] — 2026-05-11

### Added
- Первоначальная версия шаблона
- Структура из 11 разделов
- Современные параметры по NIST SP 800-63B (отмена календарной смены, длина 12+/16+)
- Особый раздел для систем с навязанными извне параметрами
- Маппинг на ISO 27001:2022 A.5.17, NIST SP 800-63B, ФСТЭК Приказ 17/21
- Полное руководство по применению с разбором частых ошибок

### Изменения по сравнению с традиционными шаблонами
- Убрана календарная смена паролей (NIST SP 800-63B)
- Разрешены и поощряются менеджеры паролей
- Минимальная длина повышена до 12 (16 для привилегированных)
- Добавлен механизм работы с системами, навязывающими старые правила
