# POL-IAM-003 — Политика управления доступом

**Статус:** Draft · **Зрелость:** ★ Core · **Версия:** 1.0

## Зачем нужна эта политика

Большинство утечек данных и инцидентов ИБ связаны с доступом: избыточные права, забытые учётные записи уволенных, общие пароли на группу, разработчики с прямым доступом к продакшену. Эта политика фиксирует жизненный цикл доступа — от создания учётной записи при найме до немедленной блокировки при увольнении — и устанавливает требования, которые предотвращают наиболее распространённые сценарии.

## Контекст применения

Подходит для организаций любого размера. Для малых команд (до 20 человек) часть ролей совмещается (IT = ответственный за ИБ), а ролевая матрица может быть простой таблицей. Для крупных организаций политика служит основой для более детальных процедур (регламентов onboarding/offboarding, PAM-систем, IdM-процессов).
