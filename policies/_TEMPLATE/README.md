# `_TEMPLATE/` — эталонная структура шаблона политики

Это **не настоящая политика**, а каркас для создания новых. Скопируйте эту папку под нужным именем и заполните файлы по образцу.

## Как использовать

```bash
# 1. Скопировать в нужный домен под слагом политики
cp -r policies/_TEMPLATE policies/02-access-control/my-new-policy

# 2. Заполнить все файлы согласно их собственным инструкциям внутри

# 3. Проверить metadata
python tools/validate-metadata.py policies/02-access-control/my-new-policy/metadata.yml

# 4. Открыть PR
```

## Что должно быть внутри готовой папки

| Файл | Обязательность | Назначение |
|---|---|---|
| `README.md` | ✅ | Описание политики, контекст, для кого |
| `TEMPLATE.md` | ✅ | Сам шаблон с плейсхолдерами |
| `GUIDE.md` | ✅ | Как применять: процесс, ошибки, советы |
| `metadata.yml` | ✅ | Машиночитаемые метаданные |
| `CHANGELOG.md` | ✅ | История этого шаблона |
| `EXAMPLES/` | ⏵ Опц. | Анонимизированные примеры применения |
