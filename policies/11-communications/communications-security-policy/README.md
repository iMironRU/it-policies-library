# POL-COM-001 — Политика безопасности корпоративных коммуникаций

**Maturity:** ◆ Standard  
**Владелец:** CISO  
**Статус:** draft

---

## Зачем нужна эта политика

Корпоративные коммуникации — одновременно основной рабочий инструмент и наиболее атакуемый вектор. Без чётких правил:

- сотрудник пересылает договор с ПДн клиентов в личный Telegram «для удобства»;
- кто-то регистрируется на конференцию с корпоративным email, и адрес попадает в базы рассылок;
- фишинговое письмо от «руководителя» успешно запрашивает перевод денег, потому что никто не проверяет SPF;
- при увольнении сотрудника его почтовый ящик остаётся активным ещё несколько месяцев.

Эта политика отвечает на вопросы:
- Какие мессенджеры и видеоплатформы разрешены для работы?
- Что можно передавать по почте, а что — только зашифрованным каналом?
- Как настроить почту, чтобы злоумышленники не могли слать письма от имени организации?
- Кто и как следит за тем, что через корпоративную почту не утекают данные?

## Ключевые решения при внедрении

1. **Выбор корпоративного мессенджера**: в 2024–2025 годах для российских организаций с требованиями по ПДн актуальны TrueConf, VK Teams (Mail.ru for Business), Яндекс Мессенджер (корпоративный), МТТ и аналоги — с хранением данных в РФ.

2. **DMARC в режиме `reject`**: начинать стоит с `p=none` (только сбор отчётов), затем переходить к `quarantine`, затем к `reject`. Переход занимает 1–3 месяца; спешка приводит к потере легитимных писем.

3. **DLP для почты**: полноценный DLP требует понимания потоков данных. Начните с базовых правил (передача ПДн, финансовых реквизитов) — это даст 80% ценности при 20% усилий. InfoWatch Traffic Monitor, Solar Dozor, Staffcop — зрелые отечественные решения.

4. **Фишинг-симуляция**: ежегодная симуляция фишинга даёт реалистичную картину готовности сотрудников. Ключевое правило: симуляция — не наказание, а обучение. Сотрудники, «попавшиеся», должны получать мгновенный обучающий материал, не нагоняй.

5. **ФЗ-374 («закон Яровой»)**: актуален для телекоммуникационных операторов и ОРИ. Большинство обычных организаций не попадают под его действие — уточните в юридическом отделе.
