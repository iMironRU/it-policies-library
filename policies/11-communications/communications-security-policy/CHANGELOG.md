# История изменений — POL-COM-001 Политика безопасности корпоративных коммуникаций

## [1.0.0] — 2026-10-02

### Added
- Первоначальная версия шаблона
- Принцип разрешённых каналов: только одобренные платформы для передачи конфиденциальной информации; {{СПИСОК_РАЗРЕШЁННЫХ_МЕССЕНДЖЕРОВ}}, {{СПИСОК_РАЗРЕШЁННЫХ_ВИДЕО}}
- Технические требования к защите электронной почты: SPF (`~all` / `-all`), DKIM (≥ 2048 бит), DMARC (не ниже `quarantine`), TLS 1.2+/MTA-STS, антиспам/антивирус через {{ПОЧТОВЫЙ_ШЛЮЗ}}, антифишинг через {{ИНСТРУМЕНТ_АНТИФИШИНГА}}
- Требования к пользователям: запрет на открытие подозрительных вложений, запрет пересылки конфиденциальных данных на личные ящики, требование сообщать о фишинге
- Шифрование вложений: S/MIME / PGP или зашифрованный архив + пароль отдельным каналом; запрет исполняемых вложений
- Требования к мессенджерам: корпоративный аккаунт через IdP/SSO; матрица допустимости данных по уровням конфиденциальности (Открытые / Внутренние / Конфиденциальные / Строго конфиденциальные); согласование ботов и интеграций
- Требования к видеоконференциям: ограничение распространения ссылок, зал ожидания/пароль для конфиденциальных встреч, уведомление перед записью, безопасность при демонстрации экрана
- Требования к криптографии: СКЗИ, сертифицированные ФСБ, для ГИС и КИИ; запрет незашифрованных протоколов
- Мониторинг коммуникаций: правовое основание (ПВТР, ознакомление под подпись), только корпоративные ресурсы, уведомление о DLP
- Хранение: {{СРОК_ХРАНЕНИЯ_ПОЧТЫ}} для почты, {{СРОК_ХРАНЕНИЯ_ПЕРЕПИСКИ}} для мессенджеров; упоминание ФЗ-374 для ОРИ
- Защита ПДн в коммуникациях: запрет незащищённой передачи ПДн, минимизация, ч. 5 ст. 18 ФЗ-152
- Матрица ответственности: ИБ / Администратор почты / IT / Сотрудники / Руководители
- Контроль: непрерывный (почтовый шлюз + DLP), ежемесячный (анализ инцидентов), ежегодный (аудит SPF/DKIM/DMARC + фишинг-симуляция), при увольнении
- Руководство по применению (GUIDE.md): пошаговая настройка SPF/DKIM/DMARC (с примерами DNS-записей и команд), этапы внедрения DMARC, проверка текущего состояния, сравнение корпоративных мессенджеров для РФ, правила эффективной фишинг-симуляции, памятка для сотрудников, рекомендуемые значения плейсхолдеров

### Исправления (по результатам AI-ревью)
- §6.2: уточнена строка «Строго конфиденциальные» — убрана неопределённая «личная встреча», добавлена ссылка на `{{СПИСОК_РАЗРЕШЁННЫХ_МЕССЕНДЖЕРОВ}}` и корпоративную телефонию
- §6.4: добавлен явный запрет на передачу корпоративных данных во внешние ИИ-сервисы без DPA
- §8: детализированы требования к СКЗИ по типу системы (ГИС — Приказ №17, КИИ — Приказ №239, ИСПДн УЗ-1/УЗ-2 — ПП РФ №1119 + Приказ №21, прочие)
- §9: разграничен охват мониторинга — корпоративные учётные записи/трафик независимо от устройства vs. личные учётные записи
- §10: введён отдельный плейсхолдер `{{СРОК_ХРАНЕНИЯ_ЗАПИСЕЙ_ВКС}}` для записей видеоконференций
- §11: исправлена ссылка «ч. 5 ст. 18 ФЗ-152» → «ст. 12 ФЗ-152» (ч. 5 ст. 18 регулирует первичную локализацию ПДн, а не трансграничную передачу)
