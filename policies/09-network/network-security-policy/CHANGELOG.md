# История изменений — POL-NET-001 Политика сетевой безопасности

## [1.0.0] — 2026-10-02

### Added
- Первоначальная версия шаблона
- Раздел принципов сетевой безопасности: минимальные привилегии, сегментация, глубокая защита, видимость, управляемость изменений
- Схема семи сетевых зон: внешняя, DMZ, корпоративная, серверная, управляющая, dev/test, гостевая
- Требования к сегментации: изоляция зон МЭ, default deny между зонами, изоляция dev/prod
- Документирование топологии: состав сетевой схемы, цикл актуализации
- Управление межсетевыми экранами: default deny, реестр правил с обоснованием и сроком, ревизия {{ПЕРИОД_РЕВИЗИИ_ПРАВИЛ_FIREWALL}}, запрещённые конфигурации
- Процедура управления правилами МЭ: заявка → согласование с ИБ → реестр; срок обработки {{СРОК_ОБРАБОТКИ_ЗАЯВКИ_НА_ПРАВИЛО}}
- Требования к VPN: шифрование AES-128/256, МФА обязательна, запрет устаревших протоколов (PPTP, L2TP без IPsec)
- Политика split tunneling: запрет по умолчанию, исключения через согласование
- Управление VPN-учётными записями: отзыв при увольнении, хранение журналов {{СРОК_ХРАНЕНИЯ_СЕТЕВЫХ_ЖУРНАЛОВ}}
- Требование VPN при подключении через публичные сети
- Беспроводные сети: корпоративный {{СТАНДАРТ_WIFI_КОРПОРАТИВНЫЙ}}, гостевая {{СТАНДАРТ_WIFI_ГОСТЕВОЙ}} с изоляцией, запрет WPS, client isolation, rogue AP сканирование
- Baseline конфигурации оборудования: отключение незащищённых протоколов, замена дефолтных учётных данных, NTP, централизованное журналирование
- Ротация паролей оборудования {{СРОК_СМЕНЫ_ПАРОЛЕЙ_ОБОРУДОВАНИЯ}}, хранилище секретов
- Управляющая плоскость: доступ только из управляющей сети или jump-хоста, запрет прямого admin-доступа из пользовательской сети
- Таблица источников журналов: МЭ, VPN, коммутаторы, Wi-Fi, DNS, IDS/IPS
- Срок хранения журналов: общий {{СРОК_ХРАНЕНИЯ_СЕТЕВЫХ_ЖУРНАЛОВ}}, для ПДн — не менее 3 лет (ч. 4 ст. 21 ФЗ-152)
- Мониторинг трафика: NetFlow, IDS/IPS на периметре, SIEM
- DNS-безопасность: корпоративные резольверы, блокировка прямых запросов к внешним DNS, DNS-фильтрация обязательна, журналирование DNS
- Процедура управления изменениями в сети: 5-шаговый процесс с экстренным исключением
- Ролевая матрица ответственности: сетевой администратор, ответственный за ИБ, IT, все сотрудники
- Контроль соблюдения: ревизия МЭ, сканирование инфраструктуры, проверка baseline, пентест, актуальность схемы
- Маппинг на ISO/IEC 27001:2022 A.8.20–8.22, CIS Controls v8 12–13, NIST SP 800-53 SC-7, ФЗ-149 ст. 16, ФЗ-152 ст. 19, ФСТЭК Приказ 21 МЭ.1–МЭ.6, ЗИС.1–ЗИС.3; Приказ 17 МЭ.1–МЭ.4, ЗИС.1–ЗИС.3
- Руководство по применению (GUIDE.md): выбор зон по размеру организации, baseline по вендорам, управление правилами МЭ, выбор VPN-протоколов, Wi-Fi Enterprise vs Personal, уровни мониторинга, типичные ошибки, особенности ПДн и КИИ
