**Владелец:** CISO

## Зачем нужна эта политика

Сетевая инфраструктура — фундамент любой IT-среды. Без чётких правил управления периметром, сегментацией и мониторингом прочие меры защиты (шифрование, управление доступом, защита конечных точек) существенно теряют эффективность: злоумышленник, получивший доступ к сети, может горизонтально перемещаться по инфраструктуре.

Эта политика устанавливает базовые требования к сетевой безопасности, которые применимы в большинстве организаций независимо от размера. Она отвечает на вопросы: как делить сеть на зоны, как управлять межсетевыми экранами, как организовать удалённый доступ, как контролировать беспроводные сети и что журналировать.

## Регуляторный контекст

| Стандарт / Закон | Требования, которые покрывает шаблон |
|---|---|
| ISO/IEC 27001:2022, A.8.20–8.22 | Безопасность сетей, безопасность сетевых сервисов, сегментация |
| CIS Controls v8, 12–13 | Управление сетевой инфраструктурой, мониторинг и защита |
| NIST SP 800-53 Rev.5, SC-7 | Защита границы (boundary protection) |
| ФЗ-149, ст. 16 | Защита информации, в том числе техническими средствами |
| ФЗ-152, ст. 19 ч. 1 п. 3 | Меры по предотвращению несанкционированного доступа к ПДн |
| ФСТЭК Приказ 21, МЭ.1–МЭ.6 | Межсетевые экраны в ИСПДн |
| ФСТЭК Приказ 17, МЭ.1–МЭ.4 | Межсетевые экраны в ГИС |
| ФСТЭК Приказ 21, ЗИС.1–ЗИС.3 | Защита информационной (сетевой) инфраструктуры |

Для объектов критической информационной инфраструктуры (КИИ) применяются дополнительные требования ФСТЭК Приказ 239.

## Как использовать этот шаблон

1. Откройте `TEMPLATE.md` и заполните все плейсхолдеры (список в начале файла).
2. Убедитесь, что зоны сети в разделе 5.1 отражают реальную топологию вашей организации — добавьте или уберите строки при необходимости.
3. Проверьте регуляторные требования. Если организация обрабатывает ПДн в ИСПДн с уровнем защищённости УЗ-1 или УЗ-2, ФСТЭК МЭ-классы и требования к ЗИС могут быть строже.
4. Согласуйте с сетевым администратором фактические конфигурации baseline.
5. Подробные советы по внедрению — в `GUIDE.md`.

## Ограничения шаблона

- Шаблон не охватывает специфику промышленных сетей (OT/ICS/SCADA) — для них нужна отдельная политика с учётом МЭК 62443.
- Конкретные технические параметры (номера портов, версии протоколов) намеренно вынесены в документы более низкого уровня (стандарты, технические регламенты).
- Шаблон не заменяет проектную документацию на сетевую архитектуру.
