# История изменений — POL-CLD-001 Политика облачной безопасности

## [1.0.0] — 2026-10-02

### Added
- Первоначальная версия шаблона
- Таблица модели разделённой ответственности для IaaS/PaaS/SaaS
- Критерии оценки и допуска облачных провайдеров (сертификации, DPA, шифрование, журналирование, экспорт данных)
- Требование поручения на обработку ПДн при передаче CSP (ст. 6 ч. 3 ФЗ-152)
- Управление IAM: минимальные привилегии, запрет использования root/owner для повседневных задач
- МФА обязательна для всех учётных записей с административными правами
- Индивидуальные учётные записи, запрет совместного использования
- Ревизия прав {{СРОК_ПРОВЕРКИ_ПРАВ_ОБЛАКО}}, отзыв при увольнении
- Управление секретами: запрет встраивания в код, Secrets Manager, ротация, приоритет IAM Roles / временных токенов
- Интеграция с корпоративным IdP через SSO/SAML/OIDC
- Таблица допустимости размещения данных по классам конфиденциальности
- Шифрование at-rest (AES-256) и in-transit (TLS 1.2+/1.3)
- Customer-Managed Keys для конфиденциальных данных
- Запрет публичного доступа к хранилищам по умолчанию
- Резервное копирование в географически отдельный регион
- Изоляция сред в отдельных VPC; изоляция prod от dev/test
- Security Groups/Network ACL: default deny, запрет SSH/RDP из интернета
- Гибридные подключения через зашифрованный канал
- Baseline конфигурации на основе CIS Benchmarks для CSP
- Infrastructure as Code: хранение в VCS, статический анализ, запрет секретов в IaC
- Запрещённые конфигурации: открытые бакеты, wildcard Security Groups, ключи в коде
- Локализация ПДн граждан РФ: ст. 18.1 ч. 5 ФЗ-152; требование хранения в РФ
- Трансграничная передача ПДн: ст. 12 ФЗ-152, согласование с юридической службой
- Таблица источников облачных журналов: CloudTrail/Audit Log, Access/VPC Flow/Auth/Config
- Срок хранения журналов {{СРОК_ХРАНЕНИЯ_ОБЛАЧНЫХ_ЖУРНАЛОВ}}, отдельное защищённое хранилище
- CSPM-мониторинг: реакция на критичные оповещения в течение 4 часов
- Годовой аудит конфигурации облачных ресурсов
- Управление изменениями облака через процедуру POL-OPS-001
- Облачные инциденты: ротация ключей при компрометации; уведомление РКН 24ч/72ч при утечке ПДн (ч. 3.1 ст. 21 ФЗ-152)
- Процедура выхода из сервиса: экспорт, криптографическое стирание, подтверждение удаления
- Маппинг на ISO/IEC 27001:2022 A.5.23; ISO/IEC 27017; ISO/IEC 27018; CIS Benchmarks Cloud; CSA CCM v4; NIST SP 800-144; ФЗ-152 ст. 6 ч. 3, 18.1 ч. 5, 19, 21
- Руководство по применению (GUIDE.md): инвентаризация Shadow IT, детали локализации ПДн, типичные IAM-ошибки, CSPM-инструменты, IaC DevSecOps, реагирование на типичные облачные инциденты
