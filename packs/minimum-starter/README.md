# Минимальный стартовый пакет

Базовый набор из 13–14 политик, покрывающий около 80% типовых рисков для большинства организаций. Подходит как стартовая точка для компании любого размера, ещё не имеющей формализованной IT-документации.

## Что входит

Пакет описан в `policies.yml` — машиночитаемом списке ID шаблонов.

### Метаполитики (3)
- `POL-MTA-001` Политика управления политиками
- `POL-MTA-002` Политика управления исключениями

### Стратегия (1)
- `POL-GOV-001` Политика информационной безопасности

### Управление доступом (4)
- `POL-IAM-001` Политика управления паролями
- `POL-IAM-002` Политика MFA
- `POL-IAM-003` Политика управления доступом
- `POL-IAM-005` Политика управления учётными записями (jml)
- `POL-IAM-008` Политика секретов и vault (для NHI)

### Данные (2)
- `POL-DAT-001` Политика защиты данных
- `POL-DAT-002` Политика резервного копирования

### Реагирование и операции (3)
- `POL-SEC-001` Политика реагирования на инциденты ИБ
- `POL-OPS-001` Политика управления изменениями
- `POL-OPS-014` Политика именования

### Сервис (1)
- `POL-SVC-001` Каталог сервисов и базовый SLA

### Персонал (1)
- `POL-HRM-001` Политика допустимого использования (AUP)

### Подрядчики (1, если применимо)
- `POL-SUP-005` Политика доступа подрядчиков

## Порядок внедрения

См. [../../docs/ROADMAP.md](../../docs/ROADMAP.md), раздел «Этап 0» и «Этап 1».

Ориентировочно — 3–6 месяцев на полное внедрение для команды из 1–2 человек.

## Что НЕ входит и почему

- **Разработка ПО** (DEV-*) — нужно только разработчикам, см. пакет `software-development`
- **Облако** (CLD-*) — нужно только облачным пользователям, см. `cloud-first`
- **РФ-специфика** (RUS-*) — зависит от регуляторного контекста, см. `152-fz-aligned` и `kii-subject`
- **Threat Hunting, SOC, AI Governance** — для зрелых организаций, не для старта
- **Контейнеры, Zero Trust** — для специфических контекстов

## Как использовать

1. Прочитайте [../../docs/ROADMAP.md](../../docs/ROADMAP.md)
2. Прочитайте README каждой политики из списка
3. Внедряйте в указанном порядке
4. По мере прохождения отмечайте у себя
